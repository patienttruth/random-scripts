# Random Scripts

A collection of small scripts, userscripts, utilities, and automation tools developed to solve practical problems, improve workflows, and extend existing software.

The repository emphasizes **free software, transparency, and user control**. Scripts are shared so others can use, inspect, modify, improve, and redistribute them.

## Scripts

| Project | Description | Language |
|---|---|---|
| [Immich Ctrl+Shift File Drag](immich-ctrl-shift-drag/) | Drag original images directly from Immich thumbnails or the photo viewer into upload areas on other websites. | JavaScript |

Additional scripts will be documented here as they are added.

## Installation and Usage

Each script is maintained in its own directory and includes a README with applicable installation instructions, configuration requirements, dependencies, and known limitations.

To use a script:

1. Navigate to the script's directory.
2. Review its README and source code.
3. Follow the installation instructions.
4. Adjust configuration values for your environment.

Scripts may have different runtime requirements and are not necessarily intended to work together.

## Contributing

Contributions, bug reports, compatibility testing, and improvements are welcome.

When contributing:

- Keep scripts focused and reasonably self-contained.
- Document any required dependencies or configuration.
- Avoid hardcoding credentials, private hostnames, or other sensitive information.
- Explain significant behavior changes.
- Preserve applicable license notices.

Contributions to GPL-covered scripts must be compatible with the project's licensing terms.
